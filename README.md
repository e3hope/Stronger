# Stronger 💪

당신의 한계를 돌파하는 피트니스 트래킹 앱, **Stronger**입니다.

## 📱 주요 기능

- **오늘의 루틴**: 매일 계획된 운동 루틴을 확인하고 수행할 수 있습니다.
- **운동 기록**: 무게, 횟수, 세트 수를 직관적으로 기록하세요.
- **캘린더 & 통계**: 운동 히스토리를 캘린더로 확인하고, 주간/월간 볼륨 변화를 그래프로 확인하세요.

## 🛠 기술 스택

- **Framework**: React Native (Expo)
- **Routing**: Expo Router
- **Database**: Supabase

## 🚀 시작하기

### 설치

```bash
npm install
```

### 실행

```bash
npx expo start
```
