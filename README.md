# Stronger 💪

당신의 한계를 돌파하는 직관적인 피트니스 트래킹 & 루틴 관리 앱, **Stronger**입니다.

## 📱 주요 기능

### 1. 캘린더 & 홈 (Calendar)
- **운동 기록 관리**: 캘린더에서 날짜를 선택해 운동을 기록하거나 루틴을 추가할 수 있습니다.
- **뷰 모드 전환**: 캘린더 뷰와 리스트 뷰를 전환하여 운동 기록을 한눈에 볼 수 있습니다.
- **운동 요약**: 각 날짜별 수행한 루틴, 총 볼륨, PR 달성 여부를 직관적으로 보여줍니다.

### 2. 루틴 관리 (Routines)
- **나만의 루틴 생성**: 자주 하는 운동 조합을 루틴으로 만들어 저장하세요.
- **드래그 앤 드롭**: 운동 순서를 직관적인 드래그 앤 드롭으로 변경할 수 있습니다.
- **자동/수동 저장**: 루틴 작성 중 자동 저장 기능과 함께, 확실한 저장을 위한 수동 저장 버튼을 제공합니다.

### 3. 운동 기록 (Workout Log)
- **세트 단위 기록**: 무게(kg)와 횟수(reps)를 세트별로 상세하게 기록합니다.
- **메모 기능**: 그날의 컨디션이나 특이사항을 메모로 남길 수 있습니다.
- **키패드 최적화**: 입력 중 포커스가 유지되도록 최적화된 UX를 제공합니다.

### 4. 회원가입 및 로그인
- **간편 로그인**: Google 및 Kakao 소셜 로그인을 지원합니다.
- **이메일 로그인**: 이메일/비밀번호를 통한 회원가입 및 로그인도 가능합니다.

### 5. 통계 (Stats)
- **성장 확인**: 주간/월간 운동 볼륨 변화를 그래프로 시각화하여 성장을 확인하세요.

## 🛠 기술 스택

- **Framework**: React Native (Expo)
- **Language**: TypeScript
- **Routing**: Expo Router
- **Database & Auth**: Supabase
- **UI/UX**: React Native Reanimated, Draggable FlatList
